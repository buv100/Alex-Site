# רשימת נתונים להעברה — אלכס נכסים

סמן כל פריט כשמוכן. אפשר לשלוח בחלקים — לא חייב הכל בבת אחת.
פרטים רגישים (סיסמאות) **לא בצ׳אט פתוח** — העברה בערוץ מאובטח / ישירות ל־env ב־Vercel.

מסמכים קשורים: [SPEC.md](./SPEC.md) · [PROJECT_RULES.md](./PROJECT_RULES.md)

---

## א. מיתוג וזהות

- [ ] תמונת פרופיל / לוגו של אלכס (קובץ איכותי, רצוי ללא רקע עמוס)
- [ ] שם מלא להצגה באתר (למשל: אלכס ___ )
- [ ] כותרת משנה / סלוגן קצר (אם יש; אחרת ננסח יחד)
- [ ] טקסט "למה כדאי לעבוד עם אלכס" (5–10 משפטים מספיקים)
- [ ] רקע מקצועי קצר (שנות ניסיון, התמחות בירושלים וכו')
- [ ] העדפות צבע אם יש (אחרת ניצור מדריך מותג יוקרתי כהה-מתון)

---

## ב. פרטי קשר ותפעול

- [ ] מספר טלפון לתצוגה ול־`tel:`
- [ ] מספר WhatsApp (פרטי) לקישורי `wa.me`
- [ ] אימייל לקבלת התראות על לידים מהטופס
- [ ] האם אותו אימייל גם ליצירת קשר ציבורית?
- [ ] כתובת משרד / אזור פעילות להצגה (אם רלוונטי)
- [ ] קישורי רשתות: פייסבוק / אינסטגרם / אחר (אם יש)

---

## ג. רישוי ומשפטי

- [ ] מספר רישיון תיווך להצגה באתר
- [ ] שם מלא של בעל הרישיון כפי שמופיע ברשיון
- [ ] רכז נגישות: שם מלא
- [ ] רכז נגישות: טלפון ו/או אימייל לפניות נגישות
- [ ] האם יש עו״ד לאישור טיוטות פרטיות/תקנון לפני עלייה עם לידים אמיתיים? (כן/לא/בהמשך)
- [ ] שם העוסק / עוסק מורשה כפי שיופיע במדיניות הפרטיות (בעל שליטה במאגר)

---

## ד. שכונות ואזורי עבודה

- [ ] רשימת שכונות בירושלים שבהן אלכס עובד בפועל (לסינון באתר)
- [ ] האם יש שכונות שלא מציגים / לא רלוונטיות?

## ו. חשבונות תשתית (חינמיים)

- [ ] חשבון GitHub (אליו ייכנס הריפו)
- [ ] האם ליצור ריפו חדש תחת המשתמש שלך? שם רצוי לריפו:
- [ ] חשבון Vercel (או אישור ליצור/לחבר ל־GitHub)
- [ ] חשבון MongoDB Atlas (או אישור ליצור)
- [ ] חשבון Cloudinary (או חלופה שתאושר) להעלאת תמונות
- [ ] חשבון לשליחת מייל (Resend / חלופה) — או דחייה לשלב מאוחר בדמו

## ז. אדמין ודומיין

- [ ] אימייל/שם משתמש לכניסת אדמין של אלכס
- [ ] סיסמת אדמין חזקה — **להעברה מאובטחת בלבד** (לא כאן בצ׳אט אם אפשר)

- [ ] האם מסתפקים כרגע בכתובת `*.vercel.app`?
- [ ] אם יש דומיין בעתיד — השם הרצוי (למשל alex-nekasim.co.il)

## ח. טקסטים משפטיים ותוכן משלים

- [ ] האם לאשר לנו לנסח טיוטות: מדיניות פרטיות / תנאי שימוש / הצהרת נגישות / דיסקליימר? (מומלץ: כן, ואז תעבור עליהם)
- [ ] המלצות לקוחות — **בהמשך בלבד** (לא חוסם MVP): שם, טקסט קצר, האם מותר שם מלא/ראשי תיבות

- [ ] עדיפות: קודם אדמין מושלם / קודם אתר ציבורי יפה / שניהם במקביל (ברירת מחדל לפי SPEC: שניהם, עם דגש שאדמין חובה)

## י. סדר מומלץ למשלוח אליך

1. פרטי קשר + WhatsApp + אימייל לידים  
2. תמונת אלכס + טקסט אודות  
3. מספר רישיון + רכז נגישות  
4. רשימת שכונות  
5. 3–5 נכסים עם תמונות (להתחלת דמו אמיתי)  
6. חשבונות GitHub / Vercel / Atlas  
7. סיסמת אדמין בערוץ מאובטח  
8. שאר הנכסים + המלצות בהמשך
