## 6. נכסים (5–15) — לכל נכס

```
כותרת:
סוג עסקה: מכירה / שכירות
סוג דירה:
סטטוס: טיוטה / לפרסום / נמכר / הושכר
מחיר (או ריק = צור קשר לבירור):
חדרים / שטח / קומה / סה"כ קומות:
מעלית / חניה / מרפסת:
כיווני אוויר:
שכונה + שם רחוב בלבד:
ארנונה / ועד בית:
אוכלוסייה באזור:
תיאור:
בהזדמנות / בלעדיות:
תמונות + alt:
--- פנימי ---
שם/טלפון בעלים, כתובת מדויקת, מחיר מינ׳ למו״מ, הערות
```

## 7. סדר מומלץ למשלוח

1. Mongo URI + Cloudinary + סיסמת אדמין (env)  
2. טלפון / WhatsApp / אימייל  
3. תמונת אלכס + טקסט אודות + רישיון  
4. שכונות  
5. נכסים עם תמונות  

## 8. כלל עבודה — פרסום אחרי כל שינוי

אחרי כל שינוי משמעותי:
1. Push ל־GitHub (`main`)
2. דיפלוי ללינק חי (Vercel בפרודקשן / Pages בדמו סטטי בלבד)
3. שליחת הלינק המעודכן

**הערה:** GitHub Pages = דמו סטטי בלבד. אתר אמיתי עם DB/העלאות = Vercel (מחובר לאותו GitHub).
